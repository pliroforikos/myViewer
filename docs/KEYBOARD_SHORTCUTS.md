# Keyboard & Mouse Shortcuts: myView

Comprehensive quick reference for navigation, transformations, metadata, and viewport control in `myView`.

---

## 🧭 Navigation

| Shortcut | Description |
| :--- | :--- |
| **`Right Arrow` (`→`)** | Jump to Next image in folder |
| **`Left Arrow` (`←`)** | Jump to Previous image in folder |
| **`Space`** | Advance to Next image |
| **`Backspace`** | Return to Previous image |
| **`Page Down`** | Next image |
| **`Page Up`** | Previous image |
| **`Home`** | Jump to **First** image in current folder |
| **`End`** | Jump to **Last** image in current folder |

---

## 🔍 Zoom & Pan

| Shortcut | Description |
| :--- | :--- |
| **`Mouse Wheel Up`** | Zoom In centered at cursor position |
| **`Mouse Wheel Down`** | Zoom Out centered at cursor position |
| **`+` / `=`** | Zoom In centered at viewport center |
| **`-`** | Zoom Out centered at viewport center |
| **`F` / `0`** | **Fit to Screen** (scales image to fit window) |
| **`1`** | **1:1 Native Size** (100% pixel mapping) |
| **`Double-Click`** | Toggle between Fit to Screen and 1:1 Native Size |
| **`Left-Click + Drag`** | Pan freely across the image canvas |

---

## 🔄 Rotation & Orientation

| Shortcut | Description |
| :--- | :--- |
| **`R`** | Rotate 90° Clockwise |
| **`L`** | Rotate 90° Counter-Clockwise |
| **`H`** | Flip Horizontally |

---

## ⚙️ Sorting & View Options

| Shortcut | Description |
| :--- | :--- |
| **`S`** | Cycle sorting modes: Name Ascending (`A-Z`) → Name Descending (`Z-A`) → Date Modified (`Newest`) → Date Modified (`Oldest`) → File Size (`Largest`) → File Size (`Smallest`) |
| **`I`** | Toggle collapsible **EXIF & Metadata Sidebar** |
| **`F1`** | Open / Close **About (Περί)** dialog with creator info & license |
| **`F11`** | Toggle borderless **Fullscreen** mode |
| **`Esc`** | Cancel Crop mode, dismiss About dialog, EXIF sidebar, or exit Fullscreen |

---

## ✂️ Επεξεργασία, Περικοπή & Έγγραφα (Editing & Correction)

| Shortcut | Description |
| :--- | :--- |
| **`C`** | Enter / Exit interactive **Crop Mode** (Περικοπή εικόνας) |
| **`E`** | Enter / Exit **Horizon Straightening Mode** (Ευθυγράμμιση Ορίζοντα & μικρο-περιστροφή) |
| **`P`** | Enter / Exit **Perspective & Keystone Mode** (Διόρθωση προοπτικής & άνοιγμα γωνιών εγγράφου) |
| **`Enter`** | Open **Save As...** dialog to save edited/straightened image (in editing mode) |
| **`Esc`** | Cancel active edit/crop selection and return to standard viewer |

---

## 📁 File Operations

| Shortcut | Description |
| :--- | :--- |
| **`Ctrl + O` / `O`** | Open File dialog |
| **`Delete`** | Delete currently active image file (with confirmation dialog) |
| **`Drag & Drop`** | Drag any image file or directory from Windows Explorer directly onto the app |
